# MeetMind 接口文档（API Reference）

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0 |
| 命名空间根 | `mm` |
| 头文件根 | `src/mm/`（对外包含路径为 `mm/...`） |
| 语言标准 | C++17 |
| 依赖 | 核心库仅依赖 C++ 标准库；GUI 层依赖 Qt6 Widgets |

## 0. 通用约定

| 约定 | 说明 |
| --- | --- |
| 错误处理 | 所有可失败操作返回 `Result<T>`；核心库不抛异常 |
| 时间单位 | 时间戳与时长一律使用 `int64_t` 毫秒 |
| 文本编码 | 一律 `std::string` 承载 UTF-8；按字符操作时先转 `std::u32string` |
| 音频表示 | 内部统一「单声道 / float32 / [-1,1] / 16 kHz」 |
| 索引对齐 | 流水线保证「语音段 ↔ 转写段 ↔ 说话人标签 ↔ 句子」数量一致（失败段落以空文本占位）。<br>转写单元分组只改变「调用识别的粒度」，不影响该契约：单元内文本按成员段时长权重切分回填 |
| 数值字段 | JSON 中的指标（置信度、耗时、得分、比例）一律输出为 JSON 数字，便于程序直接消费 |
| 线程安全 | `Logger` / `sharedTokenizer` 线程安全；`Tokenizer` 实例非线程安全 |

### 1.1 `result.h`

```cpp
enum class ErrorCode { Ok, InvalidArgument, FileNotFound, IoError, FormatUnsupported,
                       ModelNotLoaded, DecodeFailed, InferenceFailed, Cancelled, Internal };
const char* toString(ErrorCode) noexcept;

struct Failure { ErrorCode code; std::string message; };
Failure fail(ErrorCode, std::string);
inline Failure fail(ErrorCode code, std::string message);

template <typename T> class Result {
public:
    Result(T value);                 // 隐式成功构造
    Result(Failure f);               // 隐式失败构造
    bool ok() const noexcept;
    explicit operator bool() const;
    ErrorCode code() const noexcept;
    const std::string& message() const noexcept;
    const T& value() const;  T& value();
    const T* operator->() const;  T* operator->();
    const T& operator*()  const;  T& operator*();
    T valueOr(T fallback) const;
};
template <> class Result<void>;      // 无返回值特化（Status 别名）
using Status = Result<void>;

class CancelToken {
    void cancel() noexcept;
    bool isCancelled() const noexcept;
    void reset() noexcept;
};
```

**用法**

```cpp
Result<AudioBuffer> r = wav::read(path);
if (!r.ok()) {
    MM_LOG_ERROR("app") << r.message();          // 读取错误信息
    return fail(r.code(), r.message());          // 向上传递
}
const AudioBuffer& buf = r.value();
return okStatus();                               // 成功（无返回值场景）
```

### 3.2 `iasr_engine.h`

```cpp
class IAsrEngine {
public:
    virtual ~IAsrEngine() = default;
    virtual std::string id() const = 0;             // "whisper" / "replay" / "null"
    virtual std::string displayName() const = 0;
    virtual AsrCapabilities capabilities() const = 0;
    virtual Result<void> initialize(const AsrModelConfig&) = 0;   // 幂等
    virtual bool ready() const = 0;
    virtual Result<AsrSegment> transcribe(const AudioBuffer& chunk, int64_t chunkStartMs,

```

**实现契约**

1. `chunk.sampleRate` 必须为 16 kHz（whisper 后端会校验并拒绝其他采样率）；
2. 返回段的时间戳必须是**绝对时间**（`chunkStartMs` + 块内偏移）；
3. 长循环中必须检查取消令牌，取消时返回 `ErrorCode::Cancelled`；
4. 失败时返回 `Failure`，不得抛异常。

| `TextRank` | `rank(nodeCount, edges, opts)`、`rankWords(sentences, window, opts)`、`rankSentences(sentences, opts)`、`sentenceSimilarity(a,b)`、`normalize(scores)` |
| `KeywordExtractor` | `extractFromTokens(...)`、`extract(text, tokenizer)` → `vector<Keyword>` |
| `ExtractiveSummarizer` | 实现 `ISummarizer`；`selectSentences(tokens, importance)`、`targetSentenceCount(n)` |
| `ActionItemExtractor` | `extract(sentences, speakerLabels)`；静态 `isActionSentence` / `extractOwner` / `extractDueDate` / `detectPriority` |
| `DecisionExtractor` | `extract(sentences)`；静态 `classify(text, &kind, &trigger)` |
| `TopicSegmenter` | `segment(sentences)`；`blockSimilarities(sentenceTokens)` |
| `MinutesBuilder` | `build(sentences, speakerLabels, stats, ISummarizer* = nullptr)`；静态 `deriveTitle` |

## 6. 编排与导出 `mm/pipeline`

### 6.1 `Pipeline`

```cpp
enum class Stage { Idle, Decode, Resample, Vad, Transcribe, Diarize, Normalize,
                   Minutes, Export, Done, Failed };

struct ProgressInfo { Stage stage; int stageIndex, stageCount; double fraction;
                      std::string message; };
using ProgressCallback = std::function<void(const ProgressInfo&)>;

class Pipeline {
    explicit Pipeline(Config config);
    Result<PipelineResult> run(CancelToken* cancel = nullptr,
                               const ProgressCallback& onProgress = nullptr);
    static int stageCount();          // = 8
    static int64_t currentRssKb();
    void setConfig(const Config&);
};
```

**报告字段语义**

| 字段 | 含义 |
| --- | --- |
| `report.totalMs` | 处理总耗时（解码→纪要），**不含导出**；导出产物要写入该字段，故不能包含自身耗时 |
| `report.exportMs` | 导出耗时；`totalMs + exportMs` 才是端到端总耗时 |
| `report.transcriptionUnitCount` | 实际调用识别引擎的次数（分组后通常远小于语音段数） |

**进度区间**

| 阶段 | 索引 | 总体区间 |
| --- | --- | --- |
| 解码 | 0 | 0–8% |
| 重采样 | 1 | 8–12% |
| 语音检测 | 2 | 12–18% |
| 转写 | 3 | 18–70% |
| 说话人分离 | 4 | 70–78% |
| 文本规范化 | 5 | 78–84% |
| 纪要生成 | 6 | 84–96% |
| 导出 | 7 | 96–100% |

**取消语义**：在阶段边界与每个转写段之间检查；取消时返回 `ErrorCode::Cancelled`，不写导出文件。

```
meetmind <音频.wav> [更多音频...] [选项]
```

| 选项 | 说明 |
| --- | --- |
